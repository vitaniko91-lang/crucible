# Crucible — Agent Workbench

A design-time workbench for AI agents. You build an agent, then prove it holds — with eval suites, an LLM judge, and version diffs — so its quality and safety are demonstrated before it ships. Crucible is the proving ground that runs before release; its companion, Relay, watches agents once they're live in production.

Designed & built by Vitalina Nikulina.

**Stack:** React 19 · TypeScript · Tailwind · Framer Motion

## Development

```bash
npm install      # install dependencies
npm run dev      # start the dev server
npm run build    # type-check and build for production
npx vitest run   # run the test suite
```
